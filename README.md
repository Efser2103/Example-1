# 🏠 London Student Accommodation Scraper

This Python project automatically scrapes student housing and hall listings (name, price, address, room type, and listing URL) from [Accommodation for Students](https://www.accommodationforstudents.com/) and saves the data into a **CSV** file.

---

## 🛠️ Requirements

- `requests` — To send HTTP requests to web pages
- `beautifulsoup4` — To parse HTML content
- `csv` — To export data into a CSV file
